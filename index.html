What is Polymorphism?

📖 Concept & Real-World Example

The word polymorphism means having many forms, and it comes from the Greek words poly (many) and morph (forms), this means one entity can take many forms.

In simple words, we can define polymorphism as the ability of a message to be displayed in more than one form.

Real-World Example: A person at the same time can have different characteristics. Like a man at the same time is a father, a husband, an employee. So the same person posses different behavior in different situations. This is called polymorphism.

Function Overloading Example

💻 C++ Code (Demo Class Example)
#include <iostream> using namespace std;   class Demo { public:     // Function with 2 parameters     void add(int a, int b) {         cout << "Sum of 2 numbers = " << a + b << endl;     }       // Function with 3 parameters     void add(int a, int b, int c) {         cout << "Sum of 3 numbers = " << a + b + c << endl;     } };   int main() {     // Object creation     Demo d;       // Calling first function     d.add(10, 20);       // Calling second function     d.add(10, 20, 30);       return 0; }   /* Output: Sum of 2 numbers = 30 Sum of 3 numbers = 60 */
